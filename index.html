Deploy Your Campus to the World

This entire university lives in a single index.html — no build tools, no frameworks to install. Four steps place it live on GitHub Pages under your own domain.

1
Create a public repository on GitHub — name it anything (e.g. pembroke.academy), or your-username.github.io to publish at your root address.
2
Commit this file as index.html at the repository root, on the main branch:
terminal 
git init
git add index.html
git commit -m "Open the Pembroke Academy campus"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/pembroke.academy.git
git push -u origin main
3
Enable Pages: in the repository open Settings → Pages, set Source: Deploy from a branch, choose branch main and folder / (root), then press Save.
4
Walk through the gates. Within about a minute the campus is live at https://YOUR-USERNAME.github.io/pembroke.academy/. For a custom domain, add pembroke.academy in the Pages "Custom domain" field, point a DNS CNAME record at YOUR-USERNAME.github.io, and tick Enforce HTTPS.
