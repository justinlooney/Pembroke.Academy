# Mixamo inbox — paste Drive links here, commit, and the workflow does the rest.
#
# Edit this file (GitHub's web editor on a phone is fine), commit it, and
# .github/workflows/mixamo.yml fetches every link, builds the characters,
# shrinks them, and commits the result to assets/.
#
# THIS IS A DATA FILE, NOT A SCRIPT. Nothing here is typed at a shell.
#
# Each block starts with "# out:" naming what to build, and lists the
# downloads that go into it. THE FIRST ENTRY IN A BLOCK CARRIES THE MESH;
# every entry after it contributes only its motion, and its own mesh is
# discarded. That is what keeps four 50MB characters from becoming four
# near-identical students at four times the weight.
#
# The name becomes the clip name; underscores become spaces.
# Share every file as "Anyone with the link" or the fetch will say so.
# Tick "In Place" on Mixamo where it is offered: the campus drives
# playback from how fast a student is really walking, so a clip that also
# carries travel fights it and the feet skate.
