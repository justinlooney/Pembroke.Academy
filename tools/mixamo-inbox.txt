# Mixamo inbox — paste Drive links here, commit, and the workflow does the rest.
#
# Edit this file (GitHub's web editor on a phone is fine), commit it, and
# .github/workflows/mixamo.yml fetches every link, builds the characters,
# shrinks them, and commits the result to assets/.
#
# THIS IS A DATA FILE, NOT A SCRIPT. Nothing here is typed at a shell.
#
# Each block starts with "# out:" naming what to build, and lists the
# downloads that go into it. THE FIRST ENTRY IN A BLOCK CARRIES THE MESH;
# every entry after it contributes only its motion, and its own mesh is
# discarded. That is what keeps four 50MB characters from becoming four
# near-identical students at four times the weight.
#
# The name becomes the clip name; underscores become spaces.
# Share every file as "Anyone with the link" or the fetch will say so.
# Tick "In Place" on Mixamo where it is offered: the campus drives
# playback from how fast a student is really walking, so a clip that also
# carries travel fights it and the feet skate.

# Snatch.fbx was landed here and then removed, having been rendered:
#
#   0.00s  deep crouch      0.48s  rising, bent forward
#   0.96s  standing         1.20s  crouch again — the LOOP, not the motion
#
# One direction, crouch to standing in about a second. It reads as a sit
# and a stand in Mixamo's preview because that preview loops: crouch,
# stand, snap back, over and over. Not a pair of clips, and not usable
# as one — reversed it is a 1.2 second drop into a squat, which is too
# fast to read as sitting and ends in a squat rather than a seat.
#
# Standing Up beats it for the ground sit on both counts: it begins at
# floor level rather than mid-squat, and takes 6.1 seconds, which is
# what a person lowering themselves actually looks like.
#
# Worth keeping the shape of that check: the name said weightlifting,
# the hips said standing-up, and only the render said which second of it
# was which.

# ── a finished character ─────────────────────────────────────────────
# A block can also be a single link to a GLB that is already a rigged,
# animated character. Those skip Blender entirely: there is nothing to
# assemble, and putting a finished character through the FBX pipeline
# can only risk what it already has. It is still shrunk before it lands.
#
# FBX and GLB cannot be mixed in one block — a finished GLB brings its
# own skeleton, so a Mixamo clip has nothing to bind to. Separate them
# into their own "# out:" blocks.
#
# This one is 80MB as downloaded, which is why it comes this way rather
# than through a browser upload.
# out: assets/stu_woman.glb
