# THIS IS A DATA FILE, NOT A SCRIPT. Nothing here is typed at a shell.

# Put "name link" on a line, commit, and .github/workflows/rig.yml
# fetches the model, binds it to the skeleton out of assets/stu_walker.glb,
# retargets that model's mocap onto it, and uploads the result — a GLB, a
# .blend, and front and side renders — as run artifacts.
#
# No Mixamo account, no browser, no drag-and-drop markers on a phone.
# The skeleton and the motion both come from a file the campus already
# ships; only the body has to arrive from anywhere.
#
# Nothing is committed. A rig has to be looked at before it goes near
# the quad: automatic weights bleed between an arm and the ribs when the
# arm is held close to the body, and no log line will tell you that.
# The renders will.
